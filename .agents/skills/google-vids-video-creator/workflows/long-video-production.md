# Long Video Production Workflow

Use for multi-minute explainers, tutorials, documentary-style videos, lessons, and long-form YouTube content.

## Pre-production
1. Define audience, learning/story outcome, runtime, chapter structure, and platform.
2. Research thoroughly; prioritize primary sources and keep a source log.
3. Write a structured script with chapters, transitions, examples, and recaps.
4. Estimate runtime, then measure generated narration and revise the plan.
5. Create a storyboard and asset inventory before large-scale generation.

## Modular production
- Divide the project into chapters or sections with clear goals.
- Use consistent title cards, lower thirds, typography, colors, and audio identity.
- Create and approve reusable character/environment references.
- Produce one chapter at a time; verify it before moving to the next.
- Maintain a manifest for all scene IDs, assets, durations, and review states.
- Save checkpoints frequently and preserve source assets.

## Editing
- Keep narration and visuals synchronized.
- Use chapter cards or visual resets where helpful.
- Vary shot composition while maintaining the visual bible.
- Use diagrams, examples, demonstrations, and on-screen keywords to clarify difficult concepts.
- Avoid long stretches of static visuals unless intentional.
- Add captions and verify technical vocabulary.

## Review
Review each chapter independently, then review the complete video for continuity, pacing, repeated information, audio consistency, and chapter transitions.

## Export
Use the available export settings. Validate the full duration, dimensions, file integrity, and playback. For long exports, ensure adequate storage and wait for an explicit completed state before checking the file.
